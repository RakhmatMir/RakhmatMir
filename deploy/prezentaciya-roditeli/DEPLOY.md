# Публикация на https://rakhmatmir.github.io/prezentaciya-roditeli/

Скопируйте содержимое этой папки (кроме `DEPLOY.md`) в корень репозитория  
https://github.com/RakhmatMir/prezentaciya-roditeli — затем push в `main`.

GitHub Actions (`.github/workflows/pages.yml`) опубликует сайт автоматически.

Альтернатива: папка `prezentaciya-roditeli/` в репозитории `RakhmatMir.github.io` — тот же URL, пока отдельный репозиторий пустой.
