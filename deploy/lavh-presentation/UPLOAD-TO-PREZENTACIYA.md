# Слайд откроется по ссылке (5 минут, без настроек)

Сайт **https://rakhmatmir.github.io/prezentaciya/** у вас уже работает.  
Нужно **один раз** добавить один файл в репозиторий `prezentaciya`.

## Шаги

1. Откройте создание файла (войдите в GitHub под своим аккаунтом):  
   **https://github.com/RakhmatMir/prezentaciya/new/main?filename=lavh.html**

2. Откройте **готовый текст слайда** (один файл, всё внутри):  
   **https://github.com/RakhmatMir/RakhmatMir/blob/main/deploy/lavh-presentation/standalone.html**

3. Нажмите **Raw** (или «Исходный»), выделите **весь** текст (`Ctrl+A`) и скопируйте (`Ctrl+C`).

4. Вставьте в поле на шаге 1. Внизу нажмите **Commit changes** (можно оставить сообщение «Add LAVH slide»).

5. Подождите **1–2 минуты** и откройте в браузере:  
   **https://rakhmatmir.github.io/prezentaciya/lavh.html**

---

Если Raw на GitHub не открывается: в репозитории **RakhmatMir** скачайте файл  
`deploy/lavh-presentation/standalone.html` (кнопка **Download** на странице файла),  
откройте его в Блокноте, скопируйте всё содержимое и вставьте в шаг 1.
